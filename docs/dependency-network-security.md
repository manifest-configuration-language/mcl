# 依存取得のネットワーク制限

MCLは依存取得時にDNSを解決し、プライベート、Loopback、Link-Local、Multicastなどの制限対象IPへの接続を拒否します。この制限は依存URLを使ったServer-Side Request Forgeryから実行環境を保護します。Proxy環境変数は依存取得に使いません。

信頼できるプライベートGit ServerやSchema Serverへ接続する場合は、運用者が`MCL_DANGEROUS_ALLOWED_PRIVATE_NETWORKS`へ許可するRFC 1918 CIDRをカンマ区切りで指定します。例えば`10.96.0.123/32`は、そのIPv4アドレスだけを許可します。CIDRはRFC 1918の範囲内である必要があり、LoopbackとLink-Localは許可されません。未設定時の既定動作は拒否です。

プライベート依存先が社内CAで署名されている場合は、運用者が`MCL_EXTERNAL_CA_FILE`にPEM形式のCA証明書ファイルを指定できます。MCLはシステムCAを維持したまま指定CAを追加します。両方の設定はPluginのパラメータではなく、MCLを実行する信頼された環境の設定として管理してください。

許可CIDRを広げると、Repository内の依存設定が接続できるプライベート宛先も増えます。必要な宛先だけを指定し、信頼できないRepositoryを評価する実行環境では許可設定を使わないでください。
